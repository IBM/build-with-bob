## What I built

A full TypeScript reimplementation of the classic 2048 sliding tile game, extended with a real-time multiplayer mode. The project was built entirely using IBM Bob as a coding assistant.

Key features:
- Full TypeScript rewrite of the original JavaScript 2048 codebase
- Two-player multiplayer mode with a dedicated `MultiplayerManager`, `MultiplayerActuator`, and `MultiplayerInputManager`
- Comprehensive test suite using Vitest covering game logic, grid operations, tile management, local storage, and all multiplayer components
- Vite-powered build toolchain with SCSS styling
